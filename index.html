設定

Gemini APIキー

ワークアウトのスクショを読み取って自動入力するのに使います。 キーはこの端末の中だけに保存され、どこにも送られません（Google の API を除く）。

バックアップ

記録とメモをまとめて JSON で書き出します。定期的に取っておくと安心です。
