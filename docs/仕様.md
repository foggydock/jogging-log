# ジョギングログ 仕様（2026-08-15 決定）

## 目的
1. 走った記録を貯める（Notion からの移行先）
2. ジョギングについて調べたモチベーションになる話をメモで貯め、走る前に振り返って背中を押してもらう

## 決めごと（新規アプリ立ち上げチェックリストに沿って）

| 項目 | 決定 |
|---|---|
| データ保存 | Supabase（Sou_Diary に `jog_` 接頭辞で間借り）＋ログイン制 |
| リポジトリ | public（GitHub Pages で iPhone から使うため）。実データは Supabase 側なのでソースに含まれない |
| 1件=1行か積み上がるか | 走り＝1回1行（`jog_runs`）／メモ＝独立（`jog_notes`）の2テーブル |
| 記録の入力 | スクショを Gemini に読ませて自動入力（＋手直し・手入力も可） |
| Gemini APIキー | 設定画面でユーザーが入力し localStorage 保存（public リポなのでコードに書かない） |
| バックアップ | JSON 書き出し／取り込みを最初から入れる |

## できないこと（合意済み）
- Apple Watch / ヘルスケアのデータを Web アプリが自動取得することはできない（HealthKit はネイティブ専用）。
  → スクショを読ませる方式で代替する。

## データ項目
`jog_runs`: 日付 / タイトル / ワークアウト時間(秒) / 距離(km) / 平均心拍 / ケイデンス / kcal / 上昇高度 / 体感 / ひとこと
※ 平均ペースは 時間÷距離 で毎回計算する（保存しない＝ずれない）

`jog_notes`: 本文 / 見出し / 出典 / タグ / お気に入り / 表示回数 / 最終表示日時

## 画面（4タブ）
1. **きょう** — 今日の一言（実データから作る励まし）＋ 貯めたメモを1枚提示（最近見ていない物を優先）＋ 記録ボタン
2. **記録** — 一覧／月別グラフ／累計・連続週数
3. **メモ** — モチベーションメモの追加・一覧・タグ絞り込み
4. **設定** — APIキー / バックアップ / Notion CSV 取り込み

## モチベーション機能（4つ全部採用）
- 調べたことをメモで貯める
- 走る前に1つ出してくる（`last_shown_at` が古い順＋お気に入り優先の重み付け）
- 記録から励ましを作る（今月の距離・先月比・自己ベストなどを文章化）
- 連続記録・積み上げの見える化（連続週数、累計距離、月別グラフ）

## 移行
Notion「ジョギング記録」を CSV で書き出し → 設定タブから取り込み。
