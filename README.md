# ジョギングログ

走った記録を貯め、走る理由（モチベーションになる話）を貯めて振り返るアプリ。

## 画面

- **きょう** … 実データから作った励まし＋しばらく見ていないメモを1枚＋記録ボタン
- **記録** … 累計・自己ベスト・月別グラフ・全記録
- **メモ** … 調べたこと／響いた言葉をタグ付きで貯める
- **設定** … Gemini APIキー、バックアップ、ログアウト

## 仕組み

| | |
|---|---|
| 保存先 | Supabase（テーブルは `jog_` 接頭辞） |
| ログイン | メール＋パスワード。RLS で自分の行しか読み書きできない |
| スクショ読み取り | Gemini 2.5 Flash。APIキーは端末の localStorage のみに保存 |
| 平均ペース | 保存せず、時間÷距離で毎回計算する（数字がずれない） |

## セットアップ

1. `sql/01_schema.sql` を Supabase の SQL Editor で実行
2. 設定タブで Gemini APIキーを保存（スクショ読み取りを使う場合）

## Notion からの移行

```bash
python3 tools/convert_notion.py notion_export/out_1.csv jogging_import.json
```

できた JSON を、アプリの「設定 > バックアップ > 取り込む」から読み込む。
同じ日付＋同じ時間の記録は重複とみなして飛ばすので、二度押しても増えない。

※ `jogging_import.json` と `notion_export/` は実データなので `.gitignore` 済み。

## 更新するとき

`index.html` の `?v=1` と `sw.js` の `CACHE = 'jog-v1'` の数字を上げてから push する。
上げ忘れると、ホーム画面に追加した端末で古い画面が出続ける。

## メモ

- Apple Watch / ヘルスケアのデータは Web アプリからは自動取得できない（HealthKit はネイティブ専用）。
  だからスクショを読み取る方式にしている。
- 時間に対して距離が長すぎる記録は「数字を確かめたい記録」として記録タブに出し、
  自己ベストの計算からは外している（Notion 時代の入力ミスが2件あった）。
